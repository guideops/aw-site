Agentic Workspace

A private, self-hosted dashboard that brings one person's calendar, mail and AI assistants into a single Command Centre.

What it does

  • Calendar: shows upcoming Google Calendar events and lets the owner add a new event.
  • Mail: shows unread and starred messages from Gmail and one other mailbox, and lets the owner save a reply as a Gmail draft.
  • Assistants: the owner's own AI assistants can read a summary of the inbox to help sort it.

What it never does

  • It never sends email. There is no send function in the software.
  • It never deletes or edits existing events or messages.
  • It never shares, sells or publishes anyone's data.

Who it is for

Agentic Workspace is a personal tool run by Guidant Operations on its own private server. It is not offered to the public, and only the owner's own Google account is connected to it.

Google access

The app asks Google for permission to read Gmail, create Gmail drafts, and view and add Google Calendar events. How that data is handled is described in the Privacy Policy.
